hophop: Open Hardware
=====================

This repository will eventually contain the design files
for hardware developed for hophop as inside the Ariel OS project.

Items
-----

* [HopHop Devkit 1](./design-decisions/hophop-devkit-1.md)

  Status: Currently, this is a sketch, while precise requirements are drafted.

Branding
--------

These boards are developed as part of the Ariel OS project (as is the hophop stack),
will run Ariel OS based software from the start,
and come with the Ariel OS logo.
