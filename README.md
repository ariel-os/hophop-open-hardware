hophop: Open Hardware
=====================

This repository will eventually contain the design files
for the hophop development kit.

Until that is complete,
we we store sketches and drafts here
and discuss precise requirements.

Purpose
-------

The development board should facilitate the development of open mobile communication applications
based on DECT-2020 NR+.

It should allow users to try our hophop,
explore audio and IP applications on it,
and gather experience with mobile use based on battery or other power sources.

Branding
--------

These boards are developed as part of the Ariel OS project (as is the hophop stack),
will run Ariel OS based software from the start,
and come with the Ariel OS logo.
