hophop: Open Hardware
=====================

This repository will contains the design files
for hardware developed for hophop.

Items
-----

* [Grasshopper Nymph](./grasshopper-nymph/README.md)

  Status: Boards built and are being tested.

Branding
--------

These boards are developed as part of the Ariel OS project (as is the hophop stack),
will run Ariel OS based software from the start,
and may come with the Ariel OS logo.
